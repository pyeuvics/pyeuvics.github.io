- **Evidence:** A signed-out HTTP HEAD request on 2026-08-02 returned
  `HTTP/2 404` from `server: GitHub.com`. Search discovery returned no result.
  No Task 9 workflow was dispatched and no deployment was authorized during
  this review.
- **Impact:** No public page, route, download, search, 404 behavior, or
  accessibility behavior can be verified at the intended address.

### R10-002 — High — Website entry pages contradicted staged public content

- **Status:** Resolved and verified locally on 2026-08-02.
- **Paths:** `content/index.md`, `content/software/installation.md`,
  `content/software/science.md`, `content/software/api.md`,
  `content/software/tutorials.md`, `content/software/workflows.md`, and

  `/software/api/`, `/software/tutorials/`, `/software/workflows/`, and
  `/software/validation/` below `/euvics.github.io/`.
- **Evidence:** The home page says “No scientific source content ... has been

  same artifact contains 51 approved, provenance-bearing pyEUVICS Markdown
  pages below `/imported/pyeuvics/`; they appear in search but not in explicit
  primary navigation.
- **Impact:** Readers receive a false publication-state statement and cannot
  navigate normally to the published package documentation. Search-only

  from the locked pyEUVICS source rather than being rewritten here.

  accurate status summaries and connect the explicit pyEUVICS navigation/landing
  pages to the staged approved documentation.
- **Retest:** Reassemble from the same locks; confirm no page claims approved
  imported content is absent, and traverse installation, science, API,
  tutorials, workflows, and validation from the primary navigation without
  search or a manually entered URL.
- **Resolution evidence:** Production reassembly generated build-specific entry
  pages from the validated publication contract. The home page links the
  approved package index; installation, science, API, tutorials, workflows, and
  validation link respectively to 5, 8, 4, 8, 13, and 9 approved pages. Each
  entry page shows the exact commit, version, status, timestamp, and known
  limitations. None of the obsolete scaffold claims appears in the artifact.

  authoritative source edit route; verify ordinary website-owned pages retain
  their appropriate website edit action.

  `6193ab3e2be39fc74d40cd7ed1f9cece993b9ecd`; zero contains
  `edit/main/content/imported/`. Website-owned pages retain their normal edit
