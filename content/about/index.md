# About this site

This repository owns website navigation, presentation, deterministic staging,
search, link transformation, and deployment. EUVICS documents and pyEUVICS
scientific/software material remain owned by their authoritative source
repositories.

The default organization-site address is `https://pyeuvics.github.io/`.
Branding, affiliations,
maintainers, contact routes, and any custom domain remain owner decisions.
